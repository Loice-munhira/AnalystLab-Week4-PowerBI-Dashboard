**Name:** Loice Munhira  
**Task:** Week 4 – Power BI Dashboard  
**Tool:** Power BI  
**Dataset:** Superstore Sales Dataset (9,994 orders, 2014–2017)

---

## 📊 Project Overview

This project involved building an interactive Power BI dashboard to analyze sales performance, profitability, and customer trends using the Superstore Sales Dataset.

---

## 📌 Key Insights

- **West Region** leads in profit — $108.42K
- **Technology** is the top category — highest sales and profit margin
- **Sales are growing** — overall positive trend from 2014 to 2017
- **Consumer segment** drives over 50% of total sales
- **Furniture category** has low profit margin — needs investigation

---

## 🛠 Tools Used

- Power BI
- DAX (for measures like Profit Margin)
- Slicers for interactivity
